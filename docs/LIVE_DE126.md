# Node-only: фактическое развёртывание de126

Проверено 27 октября 2026 года, Debian 13.7 x86_64, VPS `179.254.154.126`.
Страна IP проверена отдельно: DE. DNS двух доменов содержит прямой A без AAAA.
Секреты и персональные URL подписок в репозиторий не включены.

## Установка

- Оригинальный eGames 3.8.4, commit `93e6631aae5f7bff28eadfc45faab43150cc22c6`.
- Node-only установлен штатными функциями оригинального eGames.
- Subscription service/vhost получены его штатными `sub_ng_render_*` функциями.
  Vhost включён в существующую Nginx на `/dev/shm/nginx.sock` с TLS/PROXY protocol.
- На новом VPS только Node, Nginx и Subscription. Локальной Panel, SQL базы и
  Redis/Valkey нет. Удалённая Panel 3.4.7 работает на другом сервере.
- Фактические версии: Node 3.4.3, Xray 26.7.28 (`rw-core`), Nginx 1.30.6,
  Docker 29.9.2, Compose v5.6.1, Node.js 24.22.1.
- Приватный ключ Node получен от существующей Panel. Её cookie и token переданы
  с разрешения владельца и используются backend; публичный клиент cookie не требует.

Node получила отдельный профиль и уникальный исходный inbound `DE126-REALITY`.
Его ключи, shortIds, flow, UUID и TCP 443 сохранены при установке дополнения.
Префикс новых тегов `EGADDON-AD05996E-*` не конфликтует с другой Node панели.
Изменения профиля/Hosts/Node/Squads выполнялись через API; runtime JSON не правился.

## Подписки и идемпотентность

`de126-sub.alexsun55.ru` и прежняя страница на другом сервере вернули одинаковые
16 профилей одного ограниченного временного пользователя, включая все восемь
новой Node. Общий `SUB_PUBLIC_DOMAIN` панели не менялся. Персональная HTML-страница
на обоих доменах ответила 200 без cookie и перенаправлений.

Реальный повторный `--install`: **0 API-мутаций, 0 записей Nginx, 0 reload**.
Прямое сравнение подтвердило неизменность профиля, ключей, UUID, портов, путей,
Hosts, Compose и Nginx. Это не только unit-тест идемпотентности.

Перезапущены только три контейнера новой установки. Панель вновь видит Node
connected; все восемь профилей повторно прошли внешний клиентский HTTPS тест.
Сравнение snapshots подтвердило сохранность ключей, UUID и конфигурации.

## TLS и защита

Оба сертификата Let's Encrypt действительны до 25 января 2027 года. Проверены
hostname/chain, SAN, TLS 1.3 и ALPN h2. Webroot renewal каждого сертификата прошёл
staging reconfigure; полный `renew --dry-run --run-deploy-hooks` также успешен.
HTTP-01 обслуживается Nginx на TCP 80, deploy hook перечитывает Nginx и
перезапускает Node при обновлении её сертификата для native Hysteria2.

Node API 2222/TCP разрешён только с IP панели; generic any-protocol правило
штатного installer удалено после read-only preview и проверки TCP replacement.
Внешняя проверка: 443 доступен; 2222, 3010 и loopback transports недоступны.
Subscription опубликован только на 127.0.0.1:3010.

Неизвестные SNI/Host отклоняются. Защита удалённой панели сохранена: без cookie
её API даёт 404, с cookie без Bearer — 401. На новом VPS административного API
Panel нет. Проверенные контейнерные логи не содержат переданных credentials.
У прежней Node панели сохранены исходные профиль/Hosts и native Node Plugin.

## Исправления и пределы проверки

- HTTP-01 vhost с тем же Node domain больше не считается вторым HTTPS SelfSteal.
- GET API переживает временные transport/502/503/504 ошибки; мутации не повторяются.
- Приватный umask eGames дал публичным static assets права 0600: исправлены только
  конкретные index.html/main.js/style.css и assets directory, секреты не открывались.
- До применения subscription candidate фактический `nginx -t` выявил ошибку
  сборки vhost; production-файлы не менялись до её устранения.
- Тестовая UA `Mozilla/5.0` не выбирала HTML: проверка повторена полноценным
  браузерным User-Agent и Accept text/html. Изменять backend для этого не понадобилось.
- Зафиксирован отдельный сетевой timeout чтения прежней страницы подписок;
  диагностические GET повторяются ограниченно. Это наблюдение не доказывает
  непрерывную стабильность сети и не выдаётся за исправление первопричины.

После рестарта диагностирован ещё один 502 новой страницы: Subscription backend
сообщил timeout 10000 ms при запросе к удалённой панели, обычный TLS-connect к ней
также дал timeout. Добавлены ограниченные Nginx-повторы GET (до трёх попыток,
общий бюджет 25 секунд), без кэширования и изменения авторизации. Фактическим
образом Nginx проверена последовательность upstream 502 → 502 → 200; POST
при такой же ошибке отправляется только один раз. После изменения **12/12**
реальных JSON-подписок вернулись с HTTP 200 и ожидаемыми 16 профилями; обе страницы
снова дали одинаковый результат. Первопричина сетевых тайм-аутов не установлена.

Откат managed Nginx routes теперь сохраняет поздние сторонние настройки
Subscription/ACME и отказывается при изменении собственного блока. Он проверен
полной mocked транзакцией, повторным recovery и отдельными drift guards.

68 unit-тестов проходят на Debian 13, Windows — 66 PASS / 2 POSIX SKIP.
ShellCheck, Bash syntax и Python compilation пройдены. Настоящий rollback
работающей установки не понадобился; transaction recovery/drift проверены
автоматическими тестами. Полный reboot VPS отдельно не проверялся.

Приватные snapshots, журналы, TLS/Compose/Nginx backup и результаты находятся в
`/root/de126-audit` и `/var/lib/egames-node-injector` (0700/0600).
